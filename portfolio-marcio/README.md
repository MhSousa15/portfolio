# Portfólio — Márcio Sousa

Site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript puro.

## Estrutura

```
portfolio-marcio/
├── index.html    # Estrutura da página
├── style.css     # Estilos e responsividade
├── script.js     # Interações e animações
└── README.md
```

## Como usar

1. Clone o repositório
2. Abra `index.html` no navegador — sem dependências, sem build

## Personalizar

Antes de publicar, edite em `index.html`:
- Seu e-mail em `href="mailto:SEU_EMAIL@gmail.com"`
- Seu usuário do GitHub em `href="https://github.com/SEU_USUARIO"`
- Seu perfil do LinkedIn em `href="https://linkedin.com/in/SEU_PERFIL"`
- Links dos projetos (busque por `project-link` nos comentários)

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `portfolio`)
2. Envie os arquivos para a branch `main`
3. Vá em **Settings → Pages → Source → main / root**
4. Seu site ficará em: `https://SEU_USUARIO.github.io/portfolio`
